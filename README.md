## The line

> Meets Expectations: types 'do the thing' once a day, then supervises from the couch. Promotion denied — already at peak delegation.

131 characters. One line, nothing else.

## How it works

`main.py` (Python 3.13, standard library only) copies the stored line from
`entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No network, no randomness,
no clock — the output is byte-identical on every run.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
cat /tmp/out/entry.txt
```
